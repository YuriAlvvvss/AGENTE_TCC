🆘 SOLUÇÃO DE PROBLEMAS
────────────────────────────────────────

❌ Página branca/erro ao acessar?
  → Verifique se backend está rodando: docker ps
  → Reinicie containers: docker-compose down && docker-compose up -d
  → Limpe cache do navegador: Ctrl+Shift+Delete

❌ Botões não funcionam?
  → Verifique console: F12 → Console
  → Procure por erros vermelhos
  → Backend deve estar acessível em http://localhost:8000

❌ Chat não envia?
  → Login pode ter expirado
  → Verifique se modelo está selecionado
  → Status do sistema deve estar verde/conectado

❌ Admin panel está vazio?
  → Faça login com: admin / admin123
  → Não é user comum (usuario/usuario123)
  → Não há modelos: baixe um primeiro

🎨 PERSONALIZAÇÃO (Opcional)
────────────────────────────────────────

Quer mudar as cores?

1. Abra: web/styles/main.css
2. Localize a seção :root (linhas 1-40)
3. Modifique variáveis:
   --color-primary: #7c3aed        → Mude para nova cor roxa
   --color-primary-dark: #6d28d9   → Cor roxa escura
   --color-sidebar: #0f172a        → Cor do sidebar
   --color-text: #111827           → Cor do texto

4. Salve
5. F5 no navegador para recarregar


Quer mudar o logo?

1. Abra: web/index.html
2. Procure por: <svg class="sidebar-icon" (linha ~50)
3. Modifique o SVG ou substitua por <img>
4. Salve


Quer mudar textos/mensagens?

1. Abra: web/scripts/main.js
2. Procure pelas strings de texto
3. Modifique conforme necessário
4. Salve
