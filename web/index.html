Escolha de onde a ROSITA obtém as respostas: Ollama (local), Open Router (nuvem) ou um Gateway custom compatível com a API da OpenAI (vLLM, LM Studio, LocalAI...). A configuração é aplicada na hora e fica salva para os próximos reinícios.

Ollama

Endereço do servidor Ollama. O modelo é escolhido na aba "Modelo Ativo".

Open Router

A chave é gravada apenas no servidor e nunca é devolvida ao navegador.

Gateway custom

Servidor compatível com OpenAI; a ROSITA chama /v1/chat/completions.

Enviada como Authorization: Bearer. Deixe em branco se o gateway for aberto.
