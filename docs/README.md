# Documentação do Projeto

Esta pasta centraliza a documentação técnica e funcional da ROSITA.

- `architecture.md`: visão de arquitetura, provedores de IA (OpenRouter, Gateway) e responsabilidades.
- `ARQUITETURA.md`: decisões de arquitetura do frontend (vanilla JS sem bundler) e trabalho futuro.
- `implementation_plan.md`: plano de implementação frontend-first (sem CLI).
- `linux_startup.md`: guia para executar o script automático no Linux.
- `PLANO_MELHORIAS.md`: plano de melhorias e correções do projeto.
